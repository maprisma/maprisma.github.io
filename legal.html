We do not merge this data with any other sources. For details, see the netcup GmbH Privacy Policy.

3. Local Browser Preferences (localStorage)

Switching between dark/light mode or English/German stores your preference exclusively inside your own browser's localStorage. No personal data is shared with third parties.

4. Server-Side Release Sync & External Links to GitHub

Latest release version numbers and star counts for public Maprisma repositories are fetched and cached server-side by our German web server. Simply visiting or refreshing this website makes zero browser requests to GitHub and never transmits your IP address to GitHub.

Only when you actively follow an external link to github.com (e.g., to download a release archive or inspect source code) does your browser connect to GitHub B.V. / GitHub, Inc. under the GitHub General Privacy Statement.

5. Visitor Counter & Install Clicks

This website counts page views, visitors per day and clicks on "Download & Install" with a small script on our own web server in Germany. It sets no cookies, stores nothing in your browser for it and shares no data with third parties. To count visitors per day, a shortened hash is built from your IP address and browser identifier together with a random value that is replaced every day; the IP address itself is never stored. The hashes and the random value are deleted the next day, so you cannot be recognised across days. Only daily totals are kept. An install click sends me an e-mail with the app name, language and time, and nothing about you.

Legal basis is Art. 6(1)(f) GDPR (legitimate interest in knowing whether, and which, apps people are interested in).
